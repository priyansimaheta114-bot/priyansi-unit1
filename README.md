# Python Programming Assignments (1–8)

Beginner-friendly solutions for the first eight Unit 1 Python Programming assignment questions.

## Programs
1. `program1_gross_salary.py` — Employee gross salary using HRA and DA.
2. `program2_menu_calculations.py` — Menu-driven area and simple-interest calculations.
3. `program3_employee_bonus.py` — Employee bonus based on years of service.
4. `program4_list_operations.py` — List methods and deletion with `del`.
5. `program5_tuple_operations.py` — Tuple membership, length, access, and adding items by creating a new tuple.
6. `program6_dictionary_operations.py` — Dictionary access, `get()`, updates, and length.
7. `program7_calculator_functions.py` — Menu-driven calculator using functions.
8. `program8_percentage_grade.py` — Percentage and grade for three subjects.

## How to run
- Open this folder in PyCharm, or clone/download it from GitHub.
- Open any `.py` file.
- Click **Run**. Each program asks for input in the Run console.

Requires Python 3. No external packages are needed.
